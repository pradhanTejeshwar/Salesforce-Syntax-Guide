# Salesforce Syntax Guide

This repository contains structured Salesforce Apex syntax, including static and non-static elements, conditional statements, looping statements, synchronous and asynchronous Apex.

## Structure

- **Static & Non-Static**: Examples of static and non-static variables and methods.
- **Conditionals**: If-Else, Switch case structures.
- **Looping**: For loops, While loops, Do-while loops.
- **Synchronous Apex**: DML operations, Exception Handling.
- **Asynchronous Apex**: Future methods, Queueable, Batch, Scheduled Apex.

## How to Use

Browse the relevant folders and copy the required code snippet into your Salesforce development environment.

## Contributing

# Contributing to Salesforce Apex Syntax Guide

Thank you for your interest in contributing to this repository! 🎉  
Please follow the guidelines below to ensure smooth collaboration.

## 1. Fork the Repository  
1. Click the "Fork" button on the top right of this repository.  
2. Clone the forked repository to your local system:  
  ```sh
   git clone https://github.com/your-username/Salesforce-Syntax-Guide.git  
   cd Salesforce-Syntax-Guide  
  ```
## 2. Create a New Branch  
Create a feature branch for your changes:  
  ```sh
 git checkout -b feature-name
  ```

## 3. Make Your Changes  
- Follow the existing folder structure while adding new code.  
- Use proper naming conventions and comment on complex logic.  
- Follow Salesforce best practices for Apex development.  

## 4. Commit Your Changes  
After making modifications, commit your changes:
  ```sh
   git add .  
   git commit -m "Added/Updated: [Describe your changes]"
  ```

## 5. Push to Your Fork  
  ```sh
   git push origin feature-name
  ```

## 6. Submit a Pull Request (PR)  
1. Go to the original repository on GitHub.  
2. Click on the "Pull Requests" tab and create a new PR.  
3. Provide a clear description of the changes.  
4. Wait for the maintainers to review and merge your changes.  

## 7. Sync with the Original Repository (Optional)  
If the main repository has updates, pull the latest changes:  
  ```sh
   git checkout main  
   git pull origin main  
   git checkout feature-name  
   git merge main  
  ```
